# The Tinted Pass — Project folder

Welcome! This folder keeps your brand assets, design references, website content and development files organised.

## Start here
1. Open `00_MASTER_PROJECT_CONTEXT.md` and fill in the details you know.
2. Add your logo and brand materials to `01_BRAND_IDENTITY`.
3. Save website/Pinterest references in `02_DESIGN_REFERENCES`.
4. Add original photos, backgrounds and illustrations to `03_WEBSITE_ASSETS`.
5. Put approved written content in `04_WEBSITE_CONTENT`.
6. Put tour PDFs and itineraries in `05_TOUR_ITINERARIES`.

## Helpful file naming
Use descriptive names, for example:
- `Homepage_Hero_Reference_01.jpg`
- `Navigation_Minimal_Reference.png`
- `The_Tinted_Pass_Logo.svg`
- `Ladakh_Landscape_Original_01.jpg`

Avoid names such as `image1.png` or `final-final2.jpg`.

## Reference note template
For important references, create a matching `.txt` file and describe:
- What you like
- What you want to adapt
- What should not be copied
- Which page or section it relates to
- How important it is

## Important
Keep original image files at their best available quality. Do not add passwords, API keys or other secrets to this folder or share them with an AI assistant.
